# Suivis publies par membre

| Membre | Fichier | Auteur des mises a jour |
| --- | --- | --- |
| Son | [son.md](son.md) | Son et son manager local |
| Vincent | [vincent.md](vincent.md) | Vincent et son manager local |
| Kim | [kim.md](kim.md) | Kim et son manager local |

Les trois fichiers ont le meme format. Initialement non renseignes, ils ne
signifient pas que les membres n'ont pas commence. Chaque membre met a jour son
fichier sur sa branche de tache et le pousse pour le rendre visible aux autres.
Main contient les derniers suivis fusionnes; les branches peuvent avoir des
informations plus recentes ou des travaux paralleles.

Lire aussi les commits et les PR selon le
[protocole des managers](../managers/protocol.md). Un statut est une declaration,
pas une preuve de test ou de fusion. Le tableau commun reste l'index des taches;
ces fichiers donnent les preuves et dependances detaillees par membre.

La mise a jour du suivi personnel remplace l'obligation de modifier le tableau
global apres chaque petit commit. Le manager commun consolide les changements
de priorite, attribution et dependance dans ce tableau, dans une PR dediee.
